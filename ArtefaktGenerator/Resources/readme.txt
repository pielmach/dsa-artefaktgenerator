DSA Artefaktgenerator
---------------------------

Installation
------------

Die setup.exe prüft das Vorhandensein von Abhängigkeiten, d.h. die .NET 10.0 Desktop Runtime (x86), und intalliert diese ggf. automatisch um anschließend das Tool selbst (ArtefaktGenerator-Installer.msi) zu installieren. Vorherige Versionen des Tools solltenn zuvor manuell deinstalliert werden.
